# 🍟 McDonald's Sales Analysis — Power BI

## 📌 Project Overview

This project is a continuation of my original McDonald's Sales Analysis project, which I first created using Microsoft Excel.

After learning more data analytics tools, I revisited the same dataset and developed **four interactive dashboards in Power BI** to explore sales performance, product insights, customer ordering patterns, and overall business performance.

This project reflects my learning journey and my effort to improve my data analysis and visualization skills.

## 🎯 Project Objectives

- Analyze sales performance and revenue trends.
- Identify top-performing products by revenue and sales frequency.
- Understand ordering patterns across different hours and days.
- Track key performance indicators (KPIs).
- Present business insights through interactive dashboards.

## 🛠️ Tools & Technologies

- **Power BI** — Dashboard development and data visualization
- **DAX** — Measures and KPI calculations
- **Power Query** — Data preparation and transformation
- **Microsoft Excel** — Original analysis and dataset preparation
