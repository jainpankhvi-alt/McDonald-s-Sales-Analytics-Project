# 🍽️ Restaurant Sales & Order Analysis

## 📌 Project Overview

This project analyzes a B2C restaurant dataset to understand sales performance, customer ordering behavior, and product trends. The analysis is performed using Power Query, Power Pivot, and Excel/Power BI dashboards.

---

## 📊 Dataset

### 1. Order Details

* Contains transactional data
* Columns: Order ID, Order Date, Order Time, Item ID

### 2. Menu Items

* Contains product details
* Columns: Menu Item ID, Item Name, Category, Price

---

## 🎯 Objectives

* Analyze total revenue and sales trends
* Identify most popular menu items
* Understand order patterns by time and day
* Evaluate category-level performance
* Study customer ordering behavior

---

## 🛠️ Tools Used

* Power Query (Data Cleaning & Transformation)
* Power Pivot (Data Modeling)
* Excel / Power BI (Dashboard & Visualization)

---

## 🔄 Workflow

1. Data Cleaning using Power Query
2. Data Transformation and Feature Engineering
3. Data Modeling using Power Pivot
4. Dashboard Creation
5. Insight Generation

---

## 📈 Key Analysis

* Total Revenue
* Orders per Day
* Top Selling Items
* Revenue by Category
* Time-Based Order Analysis
* Weekday vs Weekend Comparison
